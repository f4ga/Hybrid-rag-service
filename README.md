# Hybrid RAG (В РАЗРАБОТКЕ)

Система гибридного поиска документов с использованием лексического и семантического анализа.

**ВАЖНО: Этот проект заморожен**

## Описание проекта

Hybrid RAG - это система поиска документов, которая объединяет лексический (полнотекстовый) и семантический поиск для повышения точности и релевантности результатов. Проект использует современные технологии обработки естественного языка и векторные представления текста для эффективного поиска информации в документах.

## Основные компоненты

### 1. Загрузка и обработка документов
- Поддержка различных форматов документов (PDF, DOCX, TXT)
- Извлечение текста из документов
- Разбиение текста на чанки с учетом перекрытия
- Создание векторных представлений (эмбеддингов) для каждого чанка

### 2. Хранение данных
- PostgreSQL база данных с расширением pgvector для хранения векторных представлений
- SQLAlchemy ORM для работы с базой данных
- Модели данных: Document (документ) и Chunk (фрагмент текста)

### 3. Поисковые механизмы
- **Лексический поиск**: полнотекстовый поиск по ключевым словам
- **Семантический поиск**: поиск по смысловому сходству с использованием эмбеддингов
- **Гибридный поиск**: объединение результатов лексического и семантического поиска

### 4. API
- FastAPI для создания REST API
- Эндпоинты для загрузки документов и выполнения различных типов поиска
- Валидация данных с использованием Pydantic

## Установка и запуск

### Требования
- Docker и Docker Compose
- Python 3.8+

### Быстрый запуск с Docker Compose

1. Клонируйте репозиторий
2. Создайте файл .env с настройками базы данных (см. .env.example)
3. Запустите приложение с помощью Docker Compose:
   ```
   docker-compose up -d
   ```
4. Приложение будет доступно по адресу http://localhost:8000

### Ручная установка

1. Клонируйте репозиторий
2. Установите зависимости:
   ```
   pip install -r requirements.txt
   ```
3. Создайте файл .env с настройками базы данных (см. .env.example)
4. Запустите приложение:
   ```
   uvicorn app.main:app --host 0.0.0.0 --port 8000 --reload
   ```
